# omnibase/drive

A site's cloud (« le Partage », « Cloud » on the pages): an index of folders and files, as a web
server's "Index of /", with a little more - who each folder is for, whom it is shared with by
name, a few words above it, its README under it, tags to filter by, a search through every folder,
previews, a folder as one zip, download counts, workspaces with their people and tasks - managed by
the site's team on the page itself. It is a Symfony bundle (`Base\Drive\DriveBundle`) on the core
3 or 4.
